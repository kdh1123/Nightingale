# 보안 정책

사용자는 낮음·보통(기본)·높음 감도, 기능별 활성화, 감시/제외 경로만 선택합니다. JSON·정규식·조건 빌더는 제공하지 않습니다. `SecurityPolicy`는 정책 버전, 감도, 기능 스위치, 경로 목록을 분리해 가지며 기본값 검증 실패 시 안전한 기본 정책으로 복구할 수 있도록 확장합니다.

감도가 높을수록 내부 기준은 민감해지고 알림은 늘어날 수 있습니다. 실제 수치와 detector 규칙은 Phase 1~3에서 검증된 내부 정책으로만 도입합니다. 중앙 정책 배포는 미래 확장 대상이며 Phase 0에는 없습니다.
